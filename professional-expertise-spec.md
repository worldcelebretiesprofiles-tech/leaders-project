# Professional Expertise Page

## Complete Content Structure & Admin Requirements

### Objective

The Professional Expertise Page should showcase:

* What the leader has done
* What the leader is doing now
* What the leader is capable of
* How the leader helps others
* Professional achievements and impact

This page complements the main profile and provides a complete professional identity.

---

# SECTION 1: Professional Journey

### Purpose

Show professional growth over time.

### Admin Fields

For each journey entry:

* Title
* Organization
* Start Date
* End Date
* Description
* Featured Image

### Example

Senior Cardiologist

Apollo Hospital

2010 - 2018

Worked as Senior Consultant and Head of Cardiology Department.
